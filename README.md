## Sobre o projeto

O Frame é uma aplicação web para capturar, personalizar e salvar fotografias.

## Tecnologias utilizadas

- **HTML5:** estrutura da aplicação.
- **CSS3:** estilos, responsividade e temas.
- **JavaScript:** funcionalidades e interações.
- **MediaDevices:** acesso à câmera.
- **Canvas 2D:** aplicação de filtros e textos nas fotografias.

## Funcionalidades

1. Ligar e desligar a câmera.
2. Visualizar a câmera em tempo real.
3. Capturar fotografias.
4. Aplicar filtros visuais.
5. Personalizar a identificação da foto.
6. Registrar data e horário.
7. Salvar a fotografia em PNG.
8. Alternar entre modo claro e modo escuro.
9. Salvar a preferência de tema no navegador.
10. Exibir mensagens de orientação e erro.

## Como executar

1. Abra a pasta do projeto no Visual Studio Code.
2. Instale a extensão Live Server, se necessário.
3. Clique com o botão direito em `index.html`.
4. Selecione **Open with Live Server**.
5. Clique em **Ligar câmera** e permita o acesso.
6. Escolha um filtro e capture a fotografia.
7. Clique em **Salvar imagem** para baixar o resultado.
8. Use o botão no cabeçalho para trocar o tema.
